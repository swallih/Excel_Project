# E-Commerce Delivery Performance Analytics Dashboard

## Overview
This project analyzes e-commerce delivery performance using Excel to identify trends in delivery time, delays, customer feedback, and order value across multiple platforms. An interactive dashboard was created to help stakeholders monitor operational efficiency and customer satisfaction.

## Dataset Description
The dataset contains order-level delivery information from multiple e-commerce platforms, including:
- Order details and timestamps
- Delivery time and delay indicators
- Product categories
- Order value (INR)
- Customer feedback and service ratings
- Refund request status

## Key Metrics Analyzed
- Average delivery time by platform
- Delivery delay frequency by platform
- Customer response to delivery delays
- Product category distribution
- Total order value by platform and category
- Service rating comparison across platforms

## Dashboard Features
- Interactive Excel dashboard with slicers
- Platform and product category filtering
- Visual analysis using bar charts, pie charts, and line charts
- Comparative performance analysis of Blinkit, JioMart, and Swiggy Instamart
- Clear KPI-driven layout for quick decision-making

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers & Filters
- Data Cleaning & Transformation

## Insights Generated
- Identified platforms with higher delivery delays
- Analyzed the relationship between delivery delays and refund requests
- Compared service ratings across platforms
- Highlighted high-value product categories contributing to revenue
- Evaluated customer satisfaction trends based on delivery performance

## Use Cases
- Operations performance monitoring
- Delivery efficiency analysis
- Customer satisfaction tracking
- Business decision support for logistics optimization

## Conclusion
This project demonstrates practical data analytics skills including data cleaning, KPI analysis, dashboard design, and business insight generation using Excel. It is suitable for entry-level Data Analyst roles and business intelligence reporting.
